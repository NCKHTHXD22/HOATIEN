Phase 5 — Cấu hình Nginx
5.1. Tạo Nginx config

nano /etc/nginx/sites-available/hoatien
Dán nội dung sau:


server {
    listen 80;
    server_name 123.30.48.104;   # đổi thành domain nếu có

    root /var/www/hoatien/Web/admin-dashboard/dist;
    index index.html;

    # Serve React SPA (handle client-side routing)
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Proxy API requests sang backend
    location /api/ {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_cache_bypass $http_upgrade;
    }

    # Tối ưu static assets
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
5.2. Kích hoạt và test Nginx

ln -s /etc/nginx/sites-available/hoatien /etc/nginx/sites-enabled/
nginx -t          # kiểm tra syntax
systemctl reload nginx
